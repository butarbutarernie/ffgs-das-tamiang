Informasi Data Spasial & Limitasi Sistem (FFGS DAS Tamiang)

Aplikasi ini merupakan prototipe sistem pendukung keputusan berbasis riset untuk indikasi awal (rapid screening) potensi banjir bandang pada DAS Manyak Payed / Tamiang, Provinsi Aceh.

  • Batas Resmi DAS (KLHK): Menggunakan geometri asli DAS_Tamiang_KLHK.shp (Kode: DAS130029, Wilayah Kerja: BPDAS KRUENG ACEH, Luas resmi: 562.063,36 ha, Keliling: 461,52 km), direproyeksi dari EPSG:3857 ke WGS84 (EPSG:4326).
  • Jaringan Sungai (RBI 50K BIG): Menggunakan geometri asli badan sungai poligon (SUNGAI_AR_50K.shp) dan alur sungai garis (SUNGAI_LN_50K.shp) yang dipotong tepat ke batas DAS KLHK. Catatan cakupan: Data RBI 50K yang diunggah mencakup wilayah administratif Kab. Aceh Tamiang (tengah–hilir, ~97,71°–98,28° BT); jaringan sungai hulu barat di wilayah Kab. Gayo Lues/Aceh Timur (97,31°–97,71° BT) dapat dilengkapi dari RBI 50K Kab. Gayo Lues atau ekstraksi DEMNAS/MERIT Hydro.
  • Unit Sub-DAS & Integrasi GEE/Colab: 12 zona sub-DAS bawaan dipartisi rapat di dalam batas resmi KLHK untuk simulasi interaktif. Untuk analisis hidrologi presisi berbasis satelit (JAXA GSMaP v8 + NOAA GFS + HydroSHEDS Level 12), jalankan notebook GEE/Colab lalu unggah file .geojson hasilnya melalui tombol di kanan atas.
  • Limitasi Teknis: Parameter bankfull discharge ($Q_{bf} = c \cdot A^{0.72}$) dan koreksi bias masih memerlukan kalibrasi data stasiun AWLR BWS Sumatera I dan AWS/ARG BMKG setempat. Model bersifat lumped per sub-DAS (belum menyertakan rambatan hidrodinamik 2D, efek backwater pasang surut Selat Malaka, maupun jebolnya bendungan alami longsor/debris flow).

Peringatan Operasional: Jangan gunakan hasil simulasi ini secara tunggal untuk rilis peringatan publik atau keputusan evakuasi. Selalu konfirmasi dengan layanan resmi BMKG (SAOFFGS), BWS Sumatera I, dan BPBD.
